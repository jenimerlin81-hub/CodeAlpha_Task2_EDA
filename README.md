# CodeAlpha Task 2 - Exploratory Data Analysis

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Iris dataset. The main goal is to understand the dataset, identify important patterns, analyze relationships between features, and present the findings through statistical analysis and visualizations.

## Dataset

The Iris dataset contains 150 observations and 5 columns.

### Features
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Target

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Kaggle Notebook

## Analysis Performed

- Dataset loading
- Dataset structure and information analysis
- Missing value checking
- Statistical analysis
- Feature distribution analysis
- Correlation analysis
- Data visualization
- Key findings identification

## Key Findings

- The dataset contains 150 observations.
- No missing values were found.
- Four numerical features were analyzed.
- Petal length and petal width have a strong relationship.
- The dataset contains three different Iris flower classes.
- Visualizations help to understand the distribution of the features.

## Conclusion

The Exploratory Data Analysis provided a clear understanding of the Iris dataset. Statistical analysis and visualizations helped identify important patterns, feature relationships, and characteristics of the different Iris flower measurements.
